## 2026-10-14

**问题：桌宠 emoji 显示为灰色，去掉 CSS 滤镜后用户侧刷新仍是灰色。**

- 根因（代码侧）：此前设计评审给 `.pet-sprite` 加了冷色化滤镜 `hue-rotate(195deg) saturate(.55)`，emoji 降饱和后发灰。已删除该滤镜（普通形态与 stage-2 都删），`index.html` 的 style.css 版本号 bump 到 `20261014`。
- 验证：`curl localhost:8080` 确认服务端已下发新 index.html（引用 v=20261014）且 CSS 中 `hue-rotate` 为 0 处；8080 是本机 java 进程直连 ../frontend，非 Docker 旧镜像。
- 用户侧仍看到灰色 → 判断为浏览器缓存/Service Worker 旧文件，待用户按步骤清缓存验证：Ctrl+F5 → 不行则 DevTools Application → Service Workers → Unregister 后硬刷新。
- 状态：代码已修，等用户确认视觉效果。
