**问题：`.claude/ccmetr/bin/ccmetr` 在 Git Bash 下报 `exec: python3: not found`。**
- 现象：bash 包装脚本用 `exec python3` 转发，Windows 本机只有 `python` 没有 `python3` 别名，exit 127。
- 根因：包装脚本假定 POSIX 环境存在 python3；Windows 需走 `ccmetr.cmd`。
- 处理：改用 PowerShell 调 `.claude/ccmetr/bin/ccmetr.cmd`（JSON 参数加 `--%` 停止解析符转义），attach 成功。

**问题：大扫除批量删 style.css 死块的 Python 脚本两次断言失败。**

  ②`.timeline {` 找不到 → 该规则已包含在前一个删除区间内，属重复删除，去掉该条。
- 根因：按短锚点文本定位不唯一/区间重叠；脚本在写盘前断言，文件未受损。
- 处理：修正锚点后重跑成功（style.css 4891 → 4670 行），`tools/ui_check.py` 0 error。

**问题：`mvn -B test` 首跑 51 个集成测试全报 ApplicationContext 加载失败。**
- 现象：surefire 报告根因均为 `Connection refused` / Flyway 拿不到连接。

- 处理：用系统 MySQL 8.0.26 `mysqld --datadir=.localdb/data --port=3306` 后台拉起（root/root），
  复跑仅剩 1 个失败——枚举文案统一（Enums.parse）导致断言「BUY 或 SELL」过期，更新为「BUY / SELL」后 78/78 全绿。

**问题：按钮体检过闸注册超时（`#login-gate[hidden]` 等不到）。**
