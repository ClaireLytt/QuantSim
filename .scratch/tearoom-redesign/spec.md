# Spec: 首页「雨声茶室」换装（Tearoom Home Redesign）

> Triage: `ready-for-agent`
> 来源：/prototype 五轮探索（胜出 = prototype-worldviews-3.html 变体 B，细节原型 = prototype-tearoom.html）
> + /grill 两轮决策 + 用户收窄范围（2026-10-24）：**只重构首页**，全站换装暂缓。
> 本文件取代先前的全站换装版 spec。

## Problem Statement

用户不喜欢现站 Apple 风格视觉（黑底 + systemIndigo 紫主色 + 紫青渐变），经五轮原型收敛出
「雨天 · 冷静 · 室内」的雨声茶室方向。全站一次换装改动面大（4700 行 CSS、五个视图域），
用户决定先只把**首页**（home 视图）落成茶室风格，作为真实环境里的第一块样板，看过效果再谈全站。

## Solution

首页单视图换装：在 home 视图容器作用域内落一套茶室皮肤（暖纸底、墨字、茶色点睛、衬线标题、
噪点+光晕、极轻雨丝），暗色主题下呈现配套的「深夜雨屋」。全局主题变量、其余视图、冻结区、
品牌名一概不动；首页与其余页面会出现风格断层，这是样板阶段的已知且接受的代价。

## User Stories

1. 作为玩家，我想进入首页看到暖纸色茶室界面而非紫色科技风，这样第一眼就是新气质。
2. 作为玩家，我想首页推荐卡/榜单卡呈纸面质感（纸底、细边、双层柔影），这样样板足以代表未来全站。
3. 作为玩家，我想首页标题用衬线、数字用等宽，这样茶室气质与数据可读性兼得。
4. 作为玩家，我想首页涨跌用茶红/苔绿且两主题都过对比度，这样低饱和不牺牲可读。
5. 作为老用户，我想主题切换仍然有效：首页亮色=茶室、暗色=深夜雨屋，这样夜间可用。
6. 作为玩家，我想首页背景有噪点与暖光晕、极轻雨丝，且系统减少动态时雨丝自动关闭，这样氛围不成负担。
7. 作为英文用户，我想首页新增的点睛文案（如日头/footer 一句）中英双份，这样切 EN 不漏中文。
8. 作为移动端用户，我想首页 390px 下无横向溢出、工具簇沿既有窄屏规则，这样样板不破移动端。
9. 作为玩家，我想首页既有功能（推荐入口、双榜单、全部入口区、引导 tour 定位）全部照常可点，这样换装零功能回退。
10. 作为其他视图的使用者，我想离开首页后一切如旧（含顶栏在非首页下的现有观感），这样样板不外溢。
11. 作为维护者，我想首页茶室色以作用域变量承载、不动全局 `:root` 主题变量，这样样板可整体回摘。
12. 作为维护者，我想改动带版本号 bump 与前后截图证据、独立 commit，这样好评审好回退。
13. 作为决策者（用户本人），我想看完首页样板再决定是否推广全站，这样大改动分两步走。

## Implementation Decisions

- **作用域皮肤，不动全局主题**：茶室色板（纸/墨/茶/苔/线/影，两主题各一份）定义在 home 视图
  容器作用域下（亮色一套值、`data-theme="dark"` 下深夜雨屋一套值），变量命名带 tearoom 前缀
  以免与全局撞名。全局 `:root` 主题变量、theme 引导逻辑**零改动**（默认主题不翻转——那是全站
  换装时的决策，样板阶段不做）。
- **样式归属**：首页样式按现有分域规则写进对应域文件；首页目前复用的 academy-panel 等共享类
  在 home 作用域内覆盖，不改共享类本体（避免外溢到学院等视图）。
- **字体**：Noto Serif SC（标题）/ IBM Plex Mono（数字）woff2 子集自托管，`@font-face` +
  `font-display: swap`、系统衬线兜底；`font-family` 仅在 home 作用域应用。不接 Google CDN。
- **涨跌色**：首页榜单内用 茶红（涨）/ 苔绿（跌），明度调到两主题 WCAG 达标；全站语义色变量不动。
- **氛围**：噪点 + 暖纸/苔绿光晕限 home 容器；雨丝层仅首页渲染，`prefers-reduced-motion` 关闭；
  动画时序全部显式 cubic-bezier（禁 ease-in-out/linear）。
- **点睛文案**：至多 2 处（日头问候或 footer 一句），全部走 i18n 双语键。
- **结构不动**：首页 DOM 结构、home 模块 JS 逻辑、入口/榜单数据渲染不改（纯视觉换装）；
  若个别效果必须加包裹元素，只增不删、id 不变。
- **冻结区**：顶栏工具簇布局与全局观感不动（顶栏是全站共享的，样板阶段不纳入首页皮肤）。
- 原型验证过的决策快照（取决策而非实现）：卡片=纸底+1px 柔边+双层柔影；激活下划线=茶色细线
  中点展开（cubic-bezier）；茶红/苔绿低饱和语义色。

## Testing Decisions

- 只测外部行为：真浏览器渲染结果、可点性、对比度数值、截图观感；不断言 CSS 内部组织。
- 复用既有四层体检（本仓库同类改动的 prior art）：
  - `ui_check.py`：双主题 WCAG（首页新色是硬闸门）、版本号 bump、新 i18n 键双语；
  - `npm run buttons`：首页全部按钮仍有监听、无重复 id；
  - `browse.mjs`：首页改前/改后截图各一（两主题 × 1280/390 四张为佳）；
  - `npm run smoke`：全流程回归，特别证明其他视图未被外溢影响。
- 新增断言点：切到任一非 home 视图后截图与改前一致（外溢检查，用 browse.mjs 对比某视图截图）。

## Acceptance Criteria

1. `python tools/ui_check.py` 尾行 `0 error(s)`（Story 4/7/12）。
2. 起后端后 `cd tools/ui_smoke && npm run buttons` 退出码 0（Story 9）。
3. browse.mjs 产出首页 改前/改后 截图路径（亮+暗两主题），用户看图点头（Story 1/2/3/5/13）。
4. browse.mjs `--view` 切到学院/实验室各截一张，与改前无视觉差异（Story 10/11 外溢检查）。
5. 雨丝：browse.mjs emulateMedia `reduced-motion` 后首页雨丝层无动画；正常模式截图可见噪点/光晕（Story 6）。
6. 字体：屏蔽外联加载首页，标题仍衬线，Network 无 fonts.googleapis 请求（Story 3）。
7. 390px 宽首页截图无横向滚动（smoke 双宽度步骤通过即证，Story 8）。
8. `npm run smoke` 全绿尾行 + `git status` 干净 + 一个英文 commit（Story 12）。

## Out of Scope

- 其余四个视图域、全局主题变量、默认主题翻转、ECharts 全局系列色（首页无图表则不涉及）；
- 顶栏/工具簇/冻结区任何改动；
- 后端、数据管道、业务逻辑；
- 品牌名、manifest、图标；
- 原型文件删除/归档；
- design.md 重写（样板被采纳、推广全站时再重写；样板阶段以本 spec 为过渡事实来源）。

## Further Notes

- 全站版 spec 的决策（默认主题翻转、全局语义色替换、lab 蓝并轨、design.md 重写）全部**推迟**到
  用户看过首页样板点头之后，届时基于本样板起草全站版。
- 风格断层（首页茶室 vs 其余 Apple 风）是用户知情选择的样板代价，不作为缺陷报告。
- 首页当前大量复用 academy-panel 共享类——覆盖时务必限定在 home 容器作用域内，这是本次最大的
  外溢风险点，验收标准 4 专门盯它。
