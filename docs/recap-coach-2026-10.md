# AI 交易复盘教练：15 种复盘能力设计

> 2026-10-26 产出。定位：把现有复盘件（recap 报告 / biasprofile 五类偏差 / journal 理由对照 / benchmarks 四基准）升级为一个**基于玩家实际决策的教练**——不接 LLM 付费 API，全部规则+统计实现；文案由"发现模板 + 证据插值"生成。
> 三条铁律（每种能力都受其约束）：
> 1. **时点纪律**：任何评价只能使用"玩家做该决策时已可见"的信息（决策时点的 K 线/指标/持仓），用了未来数据的结论一律归入"结果复盘"并明确标注——这是防事后诸葛亮的机制而非口号；
> 2. **证据先行**：每条结论必须挂 ≥1 个可点开的证据锚（具体某笔交易/某段曲线/某个统计值），无锚结论不出现；
> 3. **不确定性三级**：`确凿`（样本充足+口径明确）/ `倾向`（样本 ≥3 但不足）/ `存疑`（单例或噪声区间），UI 用实线/虚线/点线边框区分，存疑结论默认折叠。

## 一、数据结构（先于能力定义）

```java
/** 教练发现: 一条结论 + 证据锚 + 不确定性等级。结算时生成, 随 session 落库 (JSON 列)。 */
record CoachFinding(
    String ability,        // 能力 id (下文 C1..C15)
    String verdictKey,     // 文案模板键 (i18n), 参数见 args
    List<String> args,     // 模板插值 (数字/日期均为字符串化)
    Confidence confidence, // SOLID / LEAN / WEAK (确凿/倾向/存疑)
    List<Anchor> anchors,  // 证据锚: 点开即定位
    boolean hindsight)     // true = 用了未来信息的"结果复盘", UI 强制加"事后视角"角标

record Anchor(
    AnchorType type,       // TX(某笔交易) / SPAN(曲线区间) / STAT(统计值) / DAY(某交易日)
    Long txId, Integer fromIdx, Integer toIdx,  // 按 type 取用
    String statKey, String statValue)

enum Confidence { SOLID, LEAN, WEAK }
```

```java
/** 决策快照: 时点纪律的物质基础——每笔交易落库时冻结"当时可见什么"。
    现有 trade_transactions 扩一列 decision_ctx JSON (Flyway 新 V):  */
record DecisionContext(
    int tickIdx,            // 窗口内第几 tick
    BigDecimal close,       // 决策时收盘价
    BigDecimal ma5, BigDecimal ma20,      // 当时的均线 (daily_indicators 已有, 冗余冻结防口径漂移)
    BigDecimal pctFromRecentHigh,         // 距近 20 日高点的回撤 (追高判定原料)
    BigDecimal positionRatioBefore,       // 交易前仓位占比
    BigDecimal floatingPnlBefore,         // 交易前浮盈亏
    Integer holdTicksBefore)              // 交易前已持有 tick 数
```

长期能力（C13~C15）的聚合输入 = 既有 `bias_report` JSON + `day_values` 净值列 + 本表，不新增长期存储。

## 二、交互设计（结算后教练面板）

三层递进，拒绝一次性倾倒：

1. **一句话层**：结算弹窗加一行教练短评（取置信度最高的 1 条 SOLID 发现），点击展开;
2. **证据卡层**：复盘报告新增"教练"页签，发现按能力分组为卡片（结论 + 置信度边框 + 「看证据」按钮）；点证据锚 → K 线图定位高亮对应交易/区间（复用 recap 的图表实例）;
3. **深挖层**：每张卡可展开"怎么算的"（口径说明，公式与阈值明示——教练不装黑箱）与"反例检查"（本局不符合该结论的交易也列出来，有一条列一条——单方面举证是误导的温床）。

玩家反馈闭环：每张卡右上「有用/没用」两键，落库统计——没用率 >60% 的发现模板进入观察名单（规则引擎的"验收测试"）。

## 三、15 种复盘能力

### 时机分析（C1~C3）

**C1 入场时机画像**
- 数据：每笔买入的 DecisionContext（pctFromRecentHigh、ma5/ma20 相对位置）。
- 计算：把每笔买入归类到四象限（突破追入/回调低吸/下跌接刀/盘整试探）：距近高 <3% 且价>MA5 = 追入；距近高 >10% 且价<MA20 = 接刀；等等（阈值明示在深挖层）。统计本局分布 + 各象限的**后续结果**（该笔的最终已实现盈亏）。
- 证据：每类列出代表交易锚；图上四色标记买点。
- 防事后诸葛亮：**归类只用决策时点数据**（象限判定不含未来）；"该象限这次赚/亏了"是结果陈述，卡片措辞固定为"你的接刀买入这局亏了 X"而非"你不该接刀"——单局结果不支持规范性结论。
- 不确定性：单局任何象限 <3 笔 → WEAK；规范性建议只在 C13 长期版（样本 ≥20 笔）给出。

**C2 离场时机对照**
- 数据：每笔卖出 + 卖出后至窗口结束的价格路径（未来数据，显式 hindsight=true）。
- 计算：卖后 5 tick 内最高/最低价 vs 卖价 → "卖飞幅度 / 躲过幅度"；汇总本局"早卖成本"与"晚卖成本"。
- 证据：每笔卖出的"卖后小尾巴"迷你图（卖点后 5 根 K 线）。
- 防误导：卡片顶部固定印"事后视角：这些路径在你卖出时不可见"角标；且同时展示对称项——卖飞的和躲过的一起列，**不允许只展示负面**。
- 不确定性：卖出 <2 笔 → 不出此卡（单例的卖飞/躲过纯属噪声）。

**C3 犹豫成本计量**
- 数据：挂单记录（撤单/未成交）+ journal 里写了理由却未对应成交的"想法"（若有）+ AI 顾问对话时间点（advisor 已有会话记录）。
- 计算：被撤掉的挂单若当时成交，到结算日的假想损益（hindsight）；"问了顾问但没动手"的时点后续走势。
- 证据：撤单锚 + 假想损益曲线虚线段。
- 防误导：假想损益必须同时算"幸好没成交"的案例；结论模板只说"本局犹豫的净成本为 ±X"，正负都可能。
- 不确定性：撤单 <2 次 → WEAK 并折叠。

### 仓位与风险（C4~C6）

**C4 仓位-波动匹配度**
- 数据：逐日仓位占比（流水重放）× 当日已实现波动（窗口内滚动 5 日标准差，时点可得）。
- 计算：理想口径 = 波动升时仓位不升（弱检验）；逐日画"仓位曲线 vs 波动曲线"，标出"波动放大当天你反而加仓"的日子。
- 证据：双曲线叠图 + 冲突日高亮。
- 防误导：波动用**决策时点可得**的滚动历史波动，不用未来实现波动；"冲突日"只是标注，结论措辞为描述性（"3 次在波动放大当天加仓"）。
- 不确定性：窗口 20 tick 的波动估计本身粗糙 → 此卡永远不高于 LEAN，口径说明里写明原因。

**C5 回撤解剖**
- 数据：净值曲线（day_values 已落库）+ 期间持仓与交易。
- 计算：定位最大回撤段，拆解其构成：β（同期标的本身跌幅 × 平均仓位）+ 择时（段内加减仓贡献）+ 费用。输出"这段回撤里，X% 来自拿着不动，Y% 来自你在段内的操作"。
- 证据：回撤段阴影 + 段内交易锚 + 拆解瀑布小图。
- 防误导：拆解是会计恒等式（各项相加=总回撤），不是归因猜测；"来自操作"的部分再标注该操作当时的信息环境（DecisionContext）。
- 不确定性：回撤 <5% 的局不出此卡（小回撤拆解无意义）；拆解恒等式成立 → SOLID。

**C6 风险预算执行报告**
- 数据：若本局带规则（每日挑战 D 系/誓约），取规则参数；否则取玩家历史均值当"个人基线"。
- 计算：本局仓位峰值/平均仓位/最大单笔占比 vs 规则线或个人基线的偏离。
- 证据：三个 STAT 锚 + 基线虚线图。
- 防误导："偏离基线"不等于错——卡片固定配一句"偏离 + 结果"的中性组合陈述；基线来源（规则/历史均值）明示。
- 不确定性：历史 <10 局时个人基线不可靠 → LEAN 并注明"基线样本不足"。

### 交易频率（C7~C8）

**C7 过度交易体检**
- 数据：笔数、换手率、费用合计、相邻交易间隔分布（biasprofile 的 overtrade 已有雏形，本卡做单局深化）。
- 计算：费用/|总盈亏| 比值；"往返交易"检测（买出后 ≤2 tick 又买回同向）；间隔 <2 tick 的连续操作串。
- 证据：往返对的配对锚（两笔连线）+ 费用占比 STAT。
- 防误导：高频不必然错——判定锚定在"往返交易的净贡献"（扣费后这些往返赚了还是亏了），用玩家自己的数据说话。
- 不确定性：笔数 <4 → 不出卡。

**C8 情绪链识别**
- 数据：交易时点的 floatingPnlBefore + 前一笔的结果 + 间隔。
- 计算：模式匹配三种链：亏损后立刻加倍（报复性）、大赚后立刻重仓（过度自信）、连续亏损后停手 N tick（冻结）。链 = 相邻交易的条件序列，全部时点数据。
- 证据：链上交易按时序连线标注。
- 防误导：模式命中 ≠ 动机断言——文案模板固定为"这个序列**形似**报复性交易"而非"你在报复市场"；深挖层给出该模式的学术名与自查问题。
- 不确定性：单链命中 → WEAK；同链两次 → LEAN；跨局三次以上由 C13 升级为 SOLID。

### 盈亏拆解（C9~C10）

**C9 盈亏来源瀑布**
- 数据：全部已实现配对（FIFO，复用 StyleCompass 的配对器）+ 未实现持仓 + 费用 + 利息。
- 计算：总收益 = Σ各配对盈亏 + 期末浮盈亏 + 利息 - 费用；按配对大小排序，标出"一笔定乾坤"（单笔贡献 >60% 总盈亏）或"积小胜"形态。
- 证据：瀑布图 + 最大贡献笔的 TX 锚。
- 防误导：纯会计，无评价；"一笔定乾坤"的提示语是中性的（"本局结果主要由一笔决定——样本=1 的局，结论都轻拿轻放"——教练自我声明不确定性）。
- 不确定性：恒等式校验通过 → SOLID（校验不过说明数据有 bug，卡片不出并记日志）。

**C10 运气-实力初分离**
- 数据：玩家逐笔方向 vs 决策时点的模型概率（daily_predictions 已有多模型 probUp）+ 实际次日走向。
- 计算：两个命中率：「与模型一致率」（决策质量 proxy）与「与结果一致率」（运气混入）；两者背离大 = 这局结果与决策质量脱钩的信号。
- 证据：逐笔三列表（你的方向/模型概率/实际走向）。
- 防误导：**模型不是真理**——卡片首句固定声明"模型概率只是参照系之一"；且模型概率取决策时点已出的预测（预测表按日期冻结，无泄漏）。
- 不确定性：永远 ≤LEAN（单局样本 + 模型局限双重折扣，口径写明）。

### 机会成本与反事实（C11~C12）

**C11 四基准机会成本榜**
- 数据：benchmarks 已算的 买入持有/MA交叉/定投/AI 四条基准收益 + 玩家收益。
- 计算：排序 + 差值；连续跨局追踪"你最常输给哪条基准"（输给定投 ≠ 输给买入持有，教的东西不同）。
- 证据：五条净值曲线叠图（已有 settle-curve 基建）。
- 防误导：基准是**事前可执行的机械策略**（不是事后最优路径——绝不展示"最优买卖点"这种上帝视角曲线作为基准）；每条基准标注其纪律含义。
- 不确定性：SOLID（基准口径机械且已测试覆盖）。

**C12 单笔反事实沙盘**（= feature-audit C3 的教练化落地）
- 数据：玩家选定一笔交易 + 修改动作（不卖/早 3 tick/半仓）→ 引擎重放。
- 计算：重放净值 vs 实际净值；限每局 2 笔（约束逼玩家选关键笔，本身是归因训练）。
- 证据：双曲线 + 分叉点标记。
- 防误导：重放页固定横幅"反事实 = 事后视角的思想实验，不是当时应做的证明"；且重放不改 AI 对手行为（声明简化假设）。
- 不确定性：结果展示为区间？不——单路径重放是确定的，但**解释**标 WEAK："一条反事实路径不构成规律"。

### 决策-结果分离（C13）与长期模式（C14~C15）

**C13 决策质量账本（跨局）**
- 数据：每笔交易的"过程分"（入场象限纪律 + 与自设格言一致性 + 与模型概率一致性的加权）与"结果分"（该笔已实现盈亏符号），跨局累积。
- 计算：四象限账本：好决策好结果/好决策坏结果/坏决策好结果/坏决策坏结果；重点卡是右下与左上——"好决策亏钱不用改，坏决策赚钱最危险"。
- 证据：四象限散点，每点可点回原局原笔。
- 防误导：这正是本能力存在的意义——把"结果好"与"做得对"在数据结构上拆开；过程分口径全透明（深挖层列公式）。
- 不确定性：<30 笔累计 → 只展示账本不下结论；≥30 笔的象限分布差异才给 LEAN/SOLID 评语。

**C14 行为指纹月报**
- 数据：biasprofile 的五类偏差趋势 + C1 象限分布 + C8 情绪链频率的滚动 60 局窗口。
- 计算：指纹 = 最稳定的 3 个行为特征（跨局重复率 ≥70%）；逐月对比"指纹漂移"（哪个特征在减弱/新出现）。
- 证据：特征趋势线 + 每特征的历史交易锚样本（随机抽 3 笔，不挑典型——挑典型就是叙事操纵）。
- 防误导：随机抽样证据 + 重复率阈值；"改善"判定需连续两个月同向（单月波动不算）。
- 不确定性：标注每特征的样本局数；<20 局的特征不入指纹。

**C15 教练备忘录（给下一局的你）**
- 数据：C13 账本 + C14 指纹 + 本局全部 SOLID 发现。
- 计算：规则引擎选 1 条"下局最值得盯的一件事"（优先级：坏决策好结果象限 > 高频情绪链 > 最常输的基准），生成一句开局前备忘（与成长系统 D2 可执行格言衔接——玩家可一键把备忘转为格言）。
- 证据：备忘来源链（点开看它从哪几条发现推出来）。
- 防误导：一次只给一条（多条建议=没有建议）；备忘措辞是观察式（"上月你有 4 笔'形似报复'的交易，这局留意亏损后的第一笔"）不是命令式。
- 不确定性：来源发现全部 ≥LEAN 才生成；否则备忘栏显示"继续积累数据，教练还不敢指路"——**敢说"我不知道"是教练可信度的一部分**。

## 落地顺序

1. **地基**：Flyway 加 decision_ctx 列 + 交易落库时冻结 DecisionContext（TradeEngine 一处改动）；CoachFinding 生成器挂进 doSettle（与 biasReport 同位）。
2. **首发三卡**：C9 盈亏瀑布（纯会计最稳）→ C11 四基准榜（基建全有）→ C1 入场画像（DecisionContext 首个消费者）。
3. **交互层**：复盘报告"教练"页签 + 证据锚定位 + 有用/没用反馈。
4. **跨局层**：C13 账本 → C14 指纹 → C15 备忘录（依赖前两者）。
5. C12 反事实沙盘最后（引擎重放是独立工程，且 feature-audit 已单列）。
