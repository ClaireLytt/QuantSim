# 玩法创意头脑风暴 II：股票模拟 × 游戏类型跨界（10 方向 × 3 机制）

> 2026-10-26 创意探索产出。创意备忘；其中小结选出的 3 个（3.3 平仓迷宫 / 9.1 周一的一千次 / 5.3 供应链战争）已于同日实现，其余未实现。

## 1. × Roguelike

### 1.1 波动即地牢
市场波动率就是地牢深度：低波动层收益薄但安全，高波动层遍地十倍机会与秒杀陷阱。每"下一层"= 主动切换到更高波动的资产池，下去就不能回头。
- **核心循环**：选层 → 用该层波动做单 → 攒"本金血量" → 决定是否再下一层。
- **关键选择**：本金多厚才敢下层？在高波层待几天就撤？
- **输赢判定**：本金归零即死（permadeath）；通关 = 活着带 10 倍本金回到地面。
- **复玩动力**：每层资产池随机生成；死后解锁新"职业"（初始带不同对冲技能）。

### 1.2 诅咒持仓
开局随机背 3 个"诅咒"（如：每次卖出必须等 3 天 / 看不到成交量 / 盈利超 10% 强制显示给"税务怪"）。诅咒把信息不对称和交易摩擦变成 build 的一部分，玩家围绕残缺规则设计打法。
- **核心循环**：识别诅咒 → 找到诅咒下仍成立的交易模式 → 用盈利购买"解咒卷轴"。
- **关键选择**：先解哪个咒？还是干脆围绕诅咒构筑（延迟卖出 → 只做长线）？
- **输赢判定**：限定周期内净值达标；中途爆仓死。
- **复玩动力**：诅咒组合巨大，每局本质是一个不同的"残缺市场"。

### 1.3 事件种子轮回
一局 = 一个宏观种子（加息周期/科技泡沫/疫情冲击）展开的 60 天。死后保留"记忆碎片"：下一局可在 3 个时点提前看到 1 条未来新闻——但种子换了，旧经验只对"事件类型"有效，不对价格有效。
- **核心循环**：跑局 → 死亡 → 选记忆碎片 → 带着模式知识（而非答案）重开。
- **关键选择**：碎片用来验证宏观判断，还是赌单点行情？
- **输赢判定**：在任意一局内达成目标收益即"飞升"。
- **复玩动力**：元进度是"对事件类型的理解"，正是量化研究的隐喻。

## 2. × 卡牌构筑

### 2.1 信号卡组
卡 = 信息来源（财报速读、龙虎榜、卫星货运数据、小道消息）。每回合抽 5 张打 2 张，打出的卡揭示市场某个切面，再决定交易。烂卡（小道消息）费用低但有假信号概率——构筑的是**你的信息组合**。
- **核心循环**：抽卡 → 选择看什么信息 → 据此交易 → 用盈利买新卡/删卡。
- **关键选择**：删掉便宜的噪音卡 vs 留着凑手数；高费真相卡什么时候打。
- **输赢判定**：20 回合后净值赛过 AI 基准；信息费拖垮现金流即败。
- **复玩动力**：卡池随版本事件轮换（财报季卡组 / 消息市卡组）。

### 2.2 对手牌桌
和 AI 庄家打"交易对子牌"：你出"买入 100 手"，它可以出"砸盘卡"反制；它出"拉抬卡"，你手里若有"识破卡"可以跟。市场价格是双方出牌的合成结果——卡牌对抗显式模拟博弈对手盘。
- **核心循环**：读对手上轮出牌 → 预判 → 出牌合成价格 → 结算仓位盈亏。
- **关键选择**：反制卡是稀缺的——用在它的小拉抬还是憋它的总攻？
- **输赢判定**：任一方净值先翻倍或先破产。
- **复玩动力**：庄家 AI 有风格牌组（暴力庄/阴庄/合规基金）。

### 2.3 遗物复利
Roguelike 卡牌的"遗物"= 交易结构优势（免佣金、T+0 特权、提前 1 分钟看到涨跌停）。遗物只能用"放弃某种自由"换取：拿 T+0 特权就永久禁止持仓过夜。优势与枷锁成对出现。
- **核心循环**：过关 → 三选一遗物（看清代价）→ 围绕新结构改打法。
- **关键选择**：每个遗物都改变规则拓扑，选择即流派。
- **输赢判定**：五关 boss 行情（崩盘日/逼空日）全部存活。
- **复玩动力**：遗物组合产生化学反应（免佣金+高频卡=剥头皮流）。

## 3. × 密室逃脱

### 3.1 持仓拆弹
你接手一个"炸弹组合"：含隐藏雷（质押爆仓链、退市股、流动性陷阱），倒计时 20 分钟内要把组合拆到安全。每卖一笔都会震动市场（砸价），拆错顺序会引爆连锁。
- **核心循环**：读持仓线索 → 推断雷在哪 → 按安全顺序减仓 → 市场反馈验证。
- **关键选择**：先拆大雷（砸价狠）还是先清安全仓换现金垫？
- **输赢判定**：倒计时内净值保住 80% 即逃脱；连锁爆炸即失败。
- **复玩动力**：雷的类型与埋法程序生成；速通排行。

### 3.2 信息密室
你被锁在"研报室"：墙上贴满图表、桌上散落财报，其中藏着一个即将发生的重大事件的完整证据链。解谜 = 把分散线索（存货异常+高管减持+专利诉讼）拼成结论，然后只有一次下单机会。
- **核心循环**：搜房间 → 交叉验证线索 → 拼出事件 → 单次全押方向。
- **关键选择**：证据链 80% 完整时就下注，还是花掉剩余时间找最后一块（价格在走，等待有成本）？
- **输赢判定**：方向对 = 逃脱；错 = 被"套牢"在房间里看正确答案回放。
- **复玩动力**：事件剧本库 + 干扰线索（红鲱鱼）随机混入。

### 3.3 平仓迷宫
物理迷宫，每扇门是一个"交易通道"（大宗、集合竞价、盘中、暗池），通道有容量和价格冲击：你带着一个超大持仓走迷宫，每过一扇门卖掉一部分，门会根据你卖的量变窄或关闭。
- **核心循环**：看地图 → 规划减仓路径 → 过门 → 市场冲击改写后续地图。
- **关键选择**：走拥挤的低冲击门（排队耗时）还是冷门高冲击门（快但贵）？
- **输赢判定**：收盘铃响前走到出口且平均卖价达标。
- **复玩动力**：这是把 TWAP/VWAP 执行算法问题空间化——迷宫即市场微观结构，随机生成。

## 4. × 侦探推理

### 4.1 老鼠仓追踪
一只基金业绩反常地精准。你是稽查员，可调取的证据有限额（通讯记录、下单时间戳、关联账户），要在基金"销毁证据"倒计时前锁定老鼠仓的传递链条。
- **核心循环**：选证据调取 → 时间戳比对（他总比公告早 2 天）→ 收网指认。
- **关键选择**：打草惊蛇地问询（证据+1 但倒计时加速）vs 静默调证。
- **输赢判定**：链条闭环指认成功；证据不足指认 = 对方反咬，案件失败。
- **复玩动力**：传递链拓扑随机（有时稽查对象是清白的——冤案惩罚极重）。

### 4.2 价格测谎仪
嫌疑人是"价格本身"：一段走势里混着自然波动和人为操纵段。你的工具是统计测谎（成交量分布、尾盘拉抬频率、对倒特征），每用一次消耗预算，最终圈出被操纵的时间段。
- **核心循环**：目视嫌疑段 → 下统计检验 → 读 p 值式的证词 → 圈定指认。
- **关键选择**：预算花在宽扫描还是深检验？统计显著但经济上不合理的段要不要信？
- **输赢判定**：IoU（圈定段与真实操纵段重叠率）≥ 阈值。
- **复玩动力**：操纵手法库（对倒/尾盘拉/假突破）× 强度随机，本质是训练异常检测直觉。

### 4.3 遗嘱里的组合
叙事推理：富豪死前把遗产换成一个古怪组合（五只看似无关的股票+一张空单）。破解他"想说什么"——组合本身是一封信（对冲了某行业 = 他预见了什么？空单标的 = 他怀疑谁？）。
- **核心循环**：分析持仓含义 → 调查家族成员动机 → 用市场事件验证假说 → 指认真相。
- **关键选择**：按遗嘱组合跟单（赚了说明你读懂了他）vs 只做旁观推理。
- **输赢判定**：真相指认 + 跟单盈亏双轨计分。
- **复玩动力**：剧本制（每季一案），组合设计即谜面。

## 5. × 城市经营

### 5.1 上市之城
你经营一座城，城里每个产业园都是一只"可上市资产"。把产业养好 → IPO 换发展资金 → 但上市后它的"股价"受外部市场波动影响，股价崩会反噬产业（裁员、税收下滑）。实体与资本双循环互锁。
- **核心循环**：建设产业 → 择时 IPO → 用募资扩张 → 管理已上市资产的市值。
- **关键选择**：牛市贱卖成长期产业套现，还是养到熊市错过窗口？
- **输赢判定**：20 年后城市 GDP+市值综合分；连环退市触发财政破产。
- **复玩动力**：宏观周期种子不同，IPO 窗口位置完全不同。

### 5.2 交易所小镇
你运营一家小交易所：定挂牌标准、手续费率、涨跌停宽度。规则吸引不同"居民"（散户游客、做市商、庄家），生态决定成交量收入——但放松监管引来庄家短期繁荣后必有崩盘潮毁掉口碑。
- **核心循环**：调规则 → 观察生态迁移 → 收手续费 → 处理市场事故。
- **关键选择**：宽涨跌停（量大、事故多）vs 严监管（安全、门庭冷落）。
- **输赢判定**：10 年后交易所声誉+利润双达标；重大事故三次即吊销牌照。
- **复玩动力**：居民群体 AI 对规则的适应性演化，每局涌现不同生态。

### 5.3 供应链战争
经营一家制造企业，同时市场上能交易你的上下游（原材料期货、竞对股票）。套保做得好，实体经营才稳：铜价暴涨时，没买期货的你只能停产。交易不是副业，是经营的呼吸。
- **核心循环**：接订单 → 评估原料敞口 → 期货套保/裸奔 → 生产交付结算。
- **关键选择**：套保比例（全套保 = 放弃原料跌价红利）；要不要做空竞对对冲行业风险？
- **输赢判定**：企业净资产目标；现金流断裂即破产（哪怕账面有利润）。
- **复玩动力**：大宗商品行情种子 + 订单流随机；教的是"风险管理即经营"。

## 6. × 生存游戏

### 6.1 熊市七十天
确定性大熊市（类似寒冬），你的"体温"是净值、"食物"是现金流。空头收益是猎物但做空有被轧空的"冻伤"风险；分红股是篝火。把生存资源表彻底映射到金融资产属性上。
- **核心循环**：每日分配：取暖（持防御资产）/狩猎（做空）/储粮（卖资产换现金）。
- **关键选择**：风雪最猛时（恐慌底）出门狩猎还是守营地？
- **输赢判定**：70 天净值不破 40% 线即存活；期末剩余资源计分。
- **复玩动力**：熊市形态（闪崩/阴跌/假反弹）随机，假反弹是最致命的"回暖"。

### 6.2 杠杆氧气瓶
深海探宝设定：下潜深度 = 杠杆倍数，深处宝藏（高收益机会）更肥，但氧气（保证金）消耗随深度平方增长，上浮（去杠杆）需要逐级减压——波动一来，想瞬间上岸是不存在的。
- **核心循环**：规划潜深 → 下潜抓机会 → 盯氧气表 → 分级上浮。
- **关键选择**：看到更深处的宝藏，赌剩余氧气够一个来回吗？
- **输赢判定**：氧气耗尽（强平）即死；带宝上岸按深度加权计分。
- **复玩动力**：洋流（波动率曲面）每局随机；把"杠杆的不可逆性"做成身体感。

### 6.3 信息辐射区
后启示录市场：真消息是稀缺净水，假消息是辐射水。每天必须"喝"信息才能交易（不看信息 = 盲单惩罚），但每条信息有隐藏辐射值（虚假度），喝多假消息会累积"认知中毒"（界面开始对你显示扭曲的价格）。
- **核心循环**：采集信息 → 用交叉验证"净化"→ 据此交易 → 管理中毒值。
- **关键选择**：验证要花时间（机会溜走），直接喝要赌纯度。
- **输赢判定**：中毒满格 = 界面完全不可信，等效失明死亡；周期末净值计分。
- **复玩动力**：假消息生成器风格轮换；"中毒后的扭曲界面"本身是独特体验。

## 7. × 战棋

### 7.1 板块六角格
地图 = 行业关系图（上下游相邻），棋子 = 你的资金单位。占格吃该板块 beta 收益，相邻格有传导 buff/debuff（原油格暴跌，相邻航空格受益）。每回合宏观事件改写若干格地形。
- **核心循环**：布子 → 宏观事件落地 → 传导结算 → 调整阵型（调仓有滑点 = 移动力消耗）。
- **关键选择**：阵型集中（吃透一条产业链传导）vs 分散（抗地形突变）。
- **输赢判定**：回合数内资金量 vs AI 对手；被挤到无格可占判负。
- **复玩动力**：事件牌库 + 地图（行业结构）随机；本质是用空间教"相关性"。

### 7.2 多空兵种
多头 = 步兵（占格生息，耐久高），空头 = 骑兵（收割下跌快，但被"轧空地形"反杀），期权 = 弓箭手（远程押注未来格，有射程=到期日）。兵种相克即衍生品关系：你的空单敞口就是对手轧空兵的进攻目标。
- **核心循环**：侦察对手阵型（持仓）→ 配兵 → 交战结算（价格变动）→ 补员。
- **关键选择**：空头骑兵深入敌阵（重仓做空）时，留多少弓箭手（保护性期权）掩护？
- **输赢判定**：歼灭对方本金或 15 回合后净值高者胜。
- **复玩动力**：PvE 将领各有兵种偏好；镜像对局暴露你的风格弱点。

### 7.3 时间战线
棋盘横轴是未来 12 个月，你在不同月份格布置"到期棋子"（期权、定投单、解禁减持）。对手同样布子，棋子到期才显形结算——下的是对未来分布的赌注，中途只能用有限"改单权"挪子。
- **核心循环**：读对手已显形的子推测其布局 → 布自己的时间阵 → 逐月结算。
- **关键选择**：子力压在近月（确定性高赔率低）还是远月（反过来）？改单权何时用？
- **输赢判定**：12 个月结算总分。
- **复玩动力**：隐蔽布子带来的 bluff 空间——像国际象棋混扑克；教的是期限结构。

## 8. × 模拟人生

### 8.1 工资线与 K 线
模拟一个普通人 30 年：工资、房贷、结婚生子都在时间轴上，股市是背景里一直开着的另一条线。每个人生事件都是被动的"流动性冲击"（买房 = 被迫在某个时点卖股）。玩的是**人生现金流与市场周期的错配**。
- **核心循环**：过日子 → 人生事件强制现金流 → 在市场里安排资产应对 → 老去结算。
- **关键选择**：孩子出生在熊市底，教育金是割肉还是借贷扛？
- **输赢判定**：退休时财务自由度评级；中年破产 = 重开。
- **复玩动力**：同一人生事件序列 × 不同市场种子（或反之），直观看到"命 vs 运"。

### 8.2 家庭持仓会议
你扮演一家四口的"家庭 CFO"，每个家庭成员是一个有性格的委托人：老爸要炒题材股、老妈只信存款、孩子要创业借钱。每季度开家庭会议分配组合——说服成本、家庭关系值和投资收益三线并行。
- **核心循环**：听诉求 → 配置组合（违背谁的意愿谁掉好感）→ 市场结算 → 关系与净值双反馈。
- **关键选择**：用收益证明自己（需要时间）vs 顺从保和谐（组合变差）。
- **输赢判定**：十年后净值 × 家庭关系的乘积分——任何一项归零都是失败。
- **复玩动力**：家庭成员性格随机生成；熊市里的家庭会议是真正的 boss 战。

### 8.3 职业内幕墙
你的人生职业选择决定信息视野：进媒体看得到舆情先机、进银行看得到信贷数据、进工厂摸得到订单冷暖——但每种职业有"合规墙"（本行业股票禁止交易）。信息优势与交易限制绑定。
- **核心循环**：选职业 → 积累行业认知 → 在合规边界内把认知变成交易 → 跳槽换视野。
- **关键选择**：跳槽重置人脉但打开新信息面；要不要碰灰色边界（内幕交易高收益+职业生涯毁灭风险）？
- **输赢判定**：50 岁时财富+声誉双轨；内幕被抓直接 game over。
- **复玩动力**：不同职业线 = 完全不同的信息博弈；灰色诱惑的设计本身是合规教育。

## 9. × 时间循环

### 9.1 周一的一千次
同一个交易周无限循环，行情完全相同——但你的交易会扰动它（自反性）：小仓位搬运答案有效，仓位大到一定程度，你的买单会改变你记住的那个高点。循环中逐步解锁"为什么会这样"的微观结构知识。
- **核心循环**：过周 → 记录 → 重置 → 带记忆重打 → 发现自己的市场冲击 → 调整规模。
- **关键选择**：吃答案的最优仓位是多少（信息价值 vs 自我破坏的平衡点）？
- **输赢判定**：单次循环内净值达标即破环；循环次数越少评级越高。
- **复玩动力**：每个"周剧本"是一道不同的市场冲击谜题；速通文化。

### 9.2 记忆典当行
每次循环重置时，你只能带走 3 条记忆，其余典当给"店主"换初始资金。记忆有类型：价格点（精确但会被你的交易扰动）、事件（周三出利空——稳健）、规律（每天尾盘拉升——最通用）。信息被显式定价。
- **核心循环**：循环 → 死亡 → 典当台三选三 → 重开。
- **关键选择**：带答案（脆弱的 alpha）还是带规律（稳健的 beta 知识）？穷的循环多当记忆换本金？
- **输赢判定**：有限循环次数（7 次）内达成目标。
- **复玩动力**：记忆估值的权衡每局不同；"知识类型的投资组合"是隐藏主题。

### 9.3 崩盘前 48 小时
已知 48 小时后必然崩盘（你是唯一记得的人），循环目标不是自己赚钱——是**拯救**：说服 NPC 们减仓。但你的言行会改变市场路径（你劝的人卖了，崩盘提前），救的人越多，你能用的套利空间越小。
- **核心循环**：循环 → 选择救谁/怎么说 → 观察路径变化 → 重置优化方案。
- **关键选择**：自己先建空单再去救人（义利冲突），还是纯救人？
- **输赢判定**：多结局：独善其身/救了小镇/说服了所有人但崩盘没发生（于是没人信你）。
- **复玩动力**：叙事多结局 + NPC 信任网络随机；自反性悖论做成剧情。

## 10. × 叙事冒险

### 10.1 营业部众生
90 年代证券营业部群像剧：你是柜台小职员，每章通过对话选择卷入一位股民的故事（押房炒股的大叔、offshore 来的神秘客）。你的建议改变他们的命运线，而大盘走势（真实历史行情回放）是所有人头顶的天气。
- **核心循环**：对话 → 给建议（谨慎/大胆/沉默）→ 行情推进 → 人物命运分支。
- **关键选择**：对押房大叔说真话（他可能恨你错过暴涨）还是顺着他？
- **输赢判定**：无传统输赢——结局图鉴（谁家破人亡、谁全身而退）+ 你的"良心值"。
- **复玩动力**：历史行情段落轮换（94 熊、07 疯牛）；同一建议在不同行情下结局互换。

### 10.2 做空者的信
你收到匿名信：某明星公司是骗局，信里只有第一条线索。顺着调查展开章节式冒险（暗访工厂、约谈离职高管），每章结束可以加空仓——调查越深信念越足，但股价还在涨，空仓浮亏在叙事推进中真实累积。
- **核心循环**：查线索 → 信念更新 → 决定加空/减空/平仓 → 下一章。
- **关键选择**：浮亏 40% 时出现反面证据（也许它真不是骗局？）——认错平仓还是加注？
- **输赢判定**：多结局：等到崩盘（大胜）/被轧空爆仓（信念正确但死在黎明前）/及时认错（小亏保命）。
- **复玩动力**：每局"公司是否真是骗局"由种子决定——同样的证据链可能指向冤案。

### 10.3 K 线上的家族史
三代人的家族叙事：爷爷的旧账本、父亲失踪前的持仓单、你继承的券商账户。解开家族秘密的钥匙藏在三代人的交易记录里（爷爷 1992 年买的认购证、父亲 2008 年那笔反常的清仓）。阅读交易记录 = 阅读人物内心。
- **核心循环**：翻历史账页 → 在对应年代行情里"重演"那笔交易（玩一段）→ 理解人物 → 推进当代剧情。
- **关键选择**：当代线里你面临和父亲 2008 年结构相同的局——重蹈覆辙还是打破轮回？
- **输赢判定**：主线解谜完成度 + 当代那一单的抉择决定结局基调。
- **复玩动力**：重演关卡可反复挑战"换个做法会怎样"；叙事回答"交易风格是会遗传的吗"。
