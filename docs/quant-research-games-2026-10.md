# 量化研究游戏化：15 个创意

> 2026-10-26 产出。与实验台（E1~E20，已实现）的分工：实验台是"工具形"的——玩家自己找问题；本篇是"游戏形"的——系统出题、给反馈回路、让失败可玩。核心循环统一为：**提假设 → 定参数 → 跑实验 → 读结果 → 发现错 → 再来**。
> 两条红线（每个创意内置）：评分永远锚定"方法质量"而非"赚了多少"——收益数字只是实验读数之一；任何文案不承诺策略赚钱，结算语固定口径"在本数据与假设内"。
> 复用底座注记：回测引擎（arena）、实验台四件套（摩擦/分区/探索计数/铁句）、研究卡（QSR1 码）、合成行情（E13 的种子路径）、教练证据锚。
> 开发难度：S=1~2 天 / M=3~7 天 / L=2 周+。

---

## 一、策略卡牌类（1~3）

### 1. 因子卡组构筑
- **玩家目标**：用"因子卡"组一副 ≤5 张的卡组（动量卡/低波卡/反转卡/量能卡/日历卡…），在未知的历史窗口上通过三关审查。
- **实验流程**：选卡组 → 看每张卡在训练段的单卡表现 → 决定组合权重 → 跑测试段 → 三关审查（收益关：赢等权基准；稳健关：回撤与换手达标；解释关：写出 ≥30 字的"为什么这几张卡互补"）。
- **关键决策**：相似卡（动量+趋势）叠加是双倍暴露还是伪分散？高换手卡带来的费用能否被其超额覆盖？
- **结果反馈**：逐卡贡献拆解（每张卡的边际收益与边际换手）；卡组相关性矩阵小图。
- **评分规则**：三关各自过/不过（无总分排名）；通关卡组存入个人卡册，附当时的窗口标签——同一卡组在别的窗口可能死，卡册会诚实记录每次复用的成败。
- **学习价值**：因子互补性与拥挤暴露；"组合 ≠ 叠 buff"。
- **开发难度**：L（因子计算 + 卡 UI；因子沿用实验台已有指标族起步）。

### 2. 残卡修复所
- **玩家目标**：系统发你一套"残缺策略卡"（缺出场规则/缺仓位规则/止损参数损坏），修复它使其在验证段站得住。
- **实验流程**：读残卡的训练段表现（通常崩坏）→ 诊断缺哪一块 → 从备件库选补件 → 验证段检验。
- **关键决策**：残卡的问题是缺件还是本来就该扔？（约 1/4 的残卡设计为"不可修"——正确答案是提交"放弃修复"报告）。
- **结果反馈**：修复前后双曲线 + 系统的"病理报告"对照你的诊断。
- **评分规则**：诊断正确性 > 修复后收益；对不可修卡提交放弃且理由对 = 最高评价"知止"。
- **学习价值**：策略的组件化思维；识别"没救的点子"是研究者的核心能力。
- **开发难度**：M（残卡模板 × 补件库的组合，引擎复用 E7 的规则件）。

### 3. 卡牌拍卖行
- **玩家目标**：在限时拍卖里用研究预算竞拍"策略线索卡"（如"某窗口里 RSI<30 后 5 日均值 +1.2%，样本 40"），拼出一个可验证假设。
- **实验流程**：预算 100 点 → 逐轮拍卖线索卡（有真有噪声，样本数公开）→ 用拍得的线索组装假设 → 一次性验证。
- **关键决策**：样本 10 的"惊艳线索"vs 样本 200 的"平庸线索"值多少钱？——为统计强度定价是本玩法的灵魂。
- **结果反馈**：验证结果 + 每张卡的"事后真值"揭晓（噪声卡现形）。
- **评分规则**：按"预算花在真线索上的比例"与假设验证结果双轴；全拍噪声但验证前主动弃权者保底分（止损意识）。
- **学习价值**：样本量定价直觉；为信息付费的决策框架。
- **开发难度**：M（线索生成器从历史数据真算，噪声卡用打乱标签生成——噪声是真噪声不是编的）。

## 二、实验任务类（4~6）

### 4. 研究委托书
- **玩家目标**：接"委托人"的研究单（"帮我验证：放量突破在小盘股上还有效吗？"），交付一份合格的研究报告。
- **实验流程**：读委托 → 在实验台自由做（委托单会指定必须包含的要素：分区验证/摩擦口径/样本数下限）→ 用 E19 研究卡格式交付 → 委托人（规则引擎）按清单验收。
- **关键决策**：委托人预设立场（他"希望"有效）——顶着委托人期望交付否定结论，验收反而加分项"风骨"。
- **结果反馈**：逐条验收意见（缺分区声明/样本不足/结论超出证据）。
- **评分规则**：清单制（过/不过 + 风骨加分），无收益维度——委托费固定，报告质量定声誉。
- **学习价值**：研究交付的完整性；抵抗确认偏误的职业伦理。
- **开发难度**：M（委托模板 + 验收规则引擎；E19 已是交付格式）。

### 5. 复现挑战
- **玩家目标**：给你一份别人的研究卡（QSR1 码，含方法与结论），在新数据上复现——复现失败是常态，也是成果。
- **实验流程**：解码研究卡 → 按其声明的方法在另一标的/另一窗口重跑 → 提交复现报告（支持/部分支持/不支持）。
- **结果反馈**：原结论 vs 你的复现数据并排；若社区多人复现同一张卡，显示复现成功率分布。
- **关键决策**：复现失败时归因于"方法本身"还是"数据环境变了"——报告要求二选一并给论据。
- **评分规则**：复现报告的完整性计分；"不支持"的复现与"支持"的同分——系统明示：否定结果同样是贡献。
- **学习价值**：可复现性是研究的生命线；一张卡 ≠ 一条规律。
- **开发难度**：S~M（研究卡解码已有，加复现记录与聚合）。
- **联动**：好友码交换体系的天然内容——朋友间互相复现对方的研究卡。

### 6. 异常侦查令
- **玩家目标**：系统在一段行情里埋了一个结构性异常（某段数据被人为加了漂移/某段成交量被缩放），用统计工具找出它在哪、是什么。
- **实验流程**：领侦查令 → 用滚动统计量（均值/波动/量价相关）扫描 → 圈定嫌疑区间 → 指认异常类型 → 揭晓。
- **关键决策**：检验窗口开多大？窗口小则噪声误报，窗口大则异常被稀释——这就是检验功效的手感版。
- **结果反馈**：揭晓真实注入点与类型；你的圈定与真值的重叠率。
- **评分规则**：定位重叠率 × 类型正确；乱枪打鸟（圈定超过 40% 的区间）直接判无效——精确性是硬要求。
- **学习价值**：异常检测直觉；统计检验的窗口-功效权衡。
- **开发难度**：M（注入器 + 扫描工具 UI；数据底座现成）。

## 三、参数解谜类（7~9）

### 7. 参数考古
- **玩家目标**：给你一条匿名策略的净值曲线，反推它的参数（策略类型已知，如双均线）——从行为倒推配置。
- **实验流程**：观察净值曲线的"指纹"（交易频率痕迹/回撤形态）→ 提出参数假设 → 用假设参数跑一遍对比曲线 → 迭代逼近（限 5 次尝试）。
- **关键决策**：先定哪个参数？快线决定交易频率、慢线决定趋势过滤——拆解次序是解谜的策略层。
- **结果反馈**：每次尝试给曲线贴合度（相关系数 + 换手差）；5 次后揭晓真参数。
- **评分规则**：按贴合度收敛速度；一次猜中与五次逼近到同等贴合度同分——鼓励系统化搜索而非运气。
- **学习价值**：参数→行为的映射直觉（调参的逆问题）；也是读懂别人策略的侦察技能。
- **开发难度**：S（E8 网格引擎反着用）。

### 8. 鲁棒性保险箱
- **玩家目标**：选一组参数放进"保险箱"，系统对它做五重扰动（参数 ±20%/窗口平移/费率上浮/数据抖动/标的更换），全扛住才开箱。
- **实验流程**：在训练段选参数（可用地形图 E8）→ 入箱 → 看五重扰动逐项结果 → 失败则带着扰动报告回去重选。
- **关键决策**：训练段最优参数几乎必死于扰动——你愿意放弃多少"账面最优"去换鲁棒？这是高原 vs 针尖的任务化。
- **结果反馈**：五张扰动小报告（哪项扰动杀死了你的参数、差多少）。
- **评分规则**：开箱所需的尝试次数（少者精）；同时记录"放弃的账面收益"——给稳健定价。
- **学习价值**：鲁棒性的操作化定义；"最优"与"能活"的区别。
- **开发难度**：M（扰动器五件套，引擎全现成）。

### 9. 一根 K 线的证词
- **玩家目标**：系统给一组候选参数在**同一天**的不同决策（A 参数今天买、B 参数今天卖、C 观望），只看截至当日的图表，推断哪组参数"更有道理"——然后看未来揭晓，并学会"有道理 ≠ 会赚钱"。
- **实验流程**：看盘面 → 排序三组决策的合理性并写一句理由 → 揭晓后续 → 系统分别展示"合理性排序"与"结果排序"的差异。
- **关键决策**：按什么标准排合理性？（与自己的格言一致？与趋势一致？）——标准的自觉化是目的。
- **结果反馈**：双排序对照 + 长期统计（你的"合理性判断"与结果的相关性，跨局累计——多数人会发现相关性低得吓人）。
- **评分规则**：只计理由的自洽性（写了标准且前后一致），不计猜中率——猜中率单独展示但不计分，这是"决策-结果分离"（教练 C13）的游戏化。
- **学习价值**：过程与结果的分离；单日决策的信噪比有多低。
- **开发难度**：S（数据与盘面组件全现成）。

## 四、策略挑战类（10~12）

### 10. 擂台盲测赛
- **玩家目标**：提交一个策略配置参加周赛——但排名在**三段保密窗口**（赛前不公布的历史区间）上综合计算，报名即锁死配置。
- **实验流程**：周一到周三开发与自测 → 周四提交锁定 → 周五在三段盲窗上统一跑 → 发榜。
- **关键决策**：为未知市况做准备 = 不敢过拟合任何单一段——制度逼出稳健构型。
- **结果反馈**：三段各自成绩 + 综合；附"若按你训练段成绩排名你会是第几"的对照（过拟合税可视化）。
- **评分规则**：三段最差成绩权重 50%（短板定成败）+ 均值 50%；榜单双列（综合/最差段）。
- **学习价值**：面向分布而非面向样本做设计。
- **开发难度**：M（arena 已有策略提交与赛季骨架，加盲窗调度）。

### 11. 接力调参
- **玩家目标**：三人异步接力调同一个策略：每人只许动一个参数并留 30 字理由，三轮后合成品上盲测。
- **实验流程**：A 动参数 1 → B 读 A 的理由后动参数 2 → C 收尾 → 盲测结算，三人共享成绩。
- **关键决策**：顺着前人的思路还是推翻？推翻要花自己唯一的改动名额。
- **结果反馈**：三步改动的边际贡献拆解（每步让盲测成绩变好/坏多少）。
- **评分规则**：团队成绩 + "理由被下一棒采信率"（写得让人看懂也是研究能力）。
- **学习价值**：研究协作与文档化思维；参数之间的交互效应（你改的和我改的会打架）。
- **开发难度**：M（好友码体系 + 一张接力表）。

### 12. 失败博物馆策展人
- **玩家目标**：从自己的历史回测/对局里挑三件"最有教育意义的失败"，策展成一个展位（每件配 50 字败因说明），供其他玩家参观并投"受教了"票。
- **实验流程**：翻自己的失败记录 → 用教练/实验台工具做败因归因 → 写展签 → 上架。
- **关键决策**：选"亏得最多的"还是"错得最典型的"？——策展标准本身是元认知练习。
- **结果反馈**：参观者的"受教了"票与评论（预设短语评论，防审核负担）。
- **评分规则**：策展分 = 败因归因被工具证据支持的程度（展签必须引用 ≥1 个证据锚）+ 受教票；亏损金额不参与计分。
- **学习价值**：把失败资产化；归因能力的公开检验。
- **开发难度**：M~L（UGC 展位 + 预设评论 + 证据锚引用；复用教练锚结构）。

## 五、失败案例与压力测试类（13~15）

### 13. 历史爆仓重演
- **玩家目标**：进入一个根据真实风格改编的"爆仓案例"（匿名化），接管爆仓前 20 天的仓位，任务不是赚钱——是**比原主少死一点**。
- **实验流程**：读案例背景与当前持仓 → 逐日决策（减仓节奏/对冲工具）→ 与"原主路径"同屏对比 → 结算看谁的终点高。
- **关键决策**：第一天就清仓是"作弊式求生"——案例规则限制单日减仓速度（流动性约束），逼你安排撤退次序（平仓迷宫的研究版）。
- **结果反馈**：你 vs 原主的双路径 + 每个分歧点的标注；结算附原案例的真实教训摘要。
- **评分规则**：相对原主的改善幅度 + 约束遵守；跑赢大盘不加分——这是撤退演习不是抄底比赛。
- **学习价值**：危机中的流动性与次序思维；读懂爆仓的结构性原因。
- **开发难度**：M（案例库是内容活；引擎复用对局 + 预设持仓，D19 回撤修复师的深化版）。

### 14. 市况轮盘压力测试
- **玩家目标**：把你的常用策略（从回测工坊导入）放上轮盘，系统随机抽三种合成市况（E13 路径库扩充：阴跌/假突破反复/流动性枯竭/高波动横盘…）连续压测，出"气象适应性报告"。
- **实验流程**：导入策略 → 转轮盘 → 三段连跑（中途不许改）→ 报告：每种市况下的生存指标。
- **关键决策**：压测前可花"改装点"给策略加一个防御件（仓位帽/波动过滤器）——加防御必然损失顺风收益，加多少？
- **结果反馈**：雷达图：策略在 6 种市况原型上的适应谱（跨次压测累计填充）——你的策略长出一张"气象适应图"。
- **评分规则**：无排名；报告是产出本身。适应谱集齐 6 市况给档案徽记。
- **学习价值**："策略适配市况"从一句话变成一张自己的图；防御件的代价核算。
- **开发难度**：M（合成路径库扩充 + 雷达聚合；压测引擎 = E13 骨架）。

### 15. 假设法庭
- **玩家目标**：一项研究主张（如"低波动股长期跑赢"）开庭，你抽签当控方或辩方，用平台数据工具构造证据链出庭；另一玩家（或规则引擎）任对方。
- **实验流程**：抽立场 → 限时 20 分钟取证（实验台全开放）→ 各提交 3 件证据（图表+一句话论点）→ 陪审（其他玩家投票或规则评分）→ 判决与"真实文献结论"揭晓。
- **关键决策**：被迫为自己不信的立场辩护——最锋利的学习装置：你必须找出对方论证的最强版本。
- **结果反馈**：证据逐件被对方质询（预设质询选项：样本？分区？费率？幸存者？——E18 的清单变成武器库）；判决书列出双方证据的方法学强弱。
- **评分规则**：证据方法学质量计分（引用分区验证的证据 > 全样本证据），立场胜负只占小头；为"错误立场"打出高质量辩护有专属称号"魔鬼代言人"。
- **学习价值**：对抗性思维；方法学武器的攻防两用；知道文献里连"低波异象"都有争议。
- **开发难度**：L（对战编排 + 证据提交结构 + 质询系统；单人版可先用规则引擎当对手）。

## 落地排序建议

1. **S 级即刻可做**：7 参数考古、9 一根 K 线的证词、5 复现挑战——全部站在实验台与研究卡的现成地基上。
2. **M 级第一梯队**：8 鲁棒性保险箱（E8 的任务化）、4 研究委托书（E19 的验收化）、14 市况轮盘（E13 的扩展）——每个都是"把已有工具包进游戏循环"。
