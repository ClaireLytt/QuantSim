# QuantSim P0 改版多角色仿真体验报告（2026-10）

> 性质声明：P0 四项（出发大厅/极速局/本局挑战+输局奖励/里程碑）**尚未实装**，本报告是对设计稿（`motivation-loop-2026-10.md`）叠加现有真实界面底座的**纸上仿真走查**，目的是在写代码前修掉设计缺陷；§6 埋点用于上线后替换这些推演结论。情绪记录为基于用户心理模型的推演，非实测数据。

## 1. 三角色全链路仿真

### 角色① 纯新手游客"小白"（不懂金融，刷到链接点进来，预算 5 分钟）

| 步骤 | 行为与情绪 | 关键观察 |
|---|---|---|
| 打开首页 | 新首屏两张大卡（⚡极速局 / 🏆每日挑战）。😐→🙂 "极速局，3 分钟一把"看懂了。**但"每日挑战"对她是噪音**——不懂"全服同题"是什么 | 3 秒传达：极速局达标；每日挑战卡对 0 局用户是无效信息 |
| 点极速局 | 直接开局（设计里极速局跳过参数页）🙂 | 达预期：无决策瘫痪 |
| 对局 D1 | 看到 K 线 + 买/卖/下一天。😕 **第一个真摩擦：不知道该先点什么**。情境引导第 1 条（"每天只有一个决定…"）若按 ux 方案存在则化解 | 引导条目与极速局必须绑定出现，缺一即流失点 |
| D1 买入后 | 买入 toast "买入 100 股 @ 10.00" 🙂 微小掌控感 | OK |
| D2~D3 | 价格跌了，浮亏 -2%。😟 **她不知道 -2% 是"正常波动"还是"我完了"** | 缺口：新手局浮亏需要一次性标尺提示（"单日 ±3% 很常见"），P0 内文案级可加 |
| D3 里程碑 | 5 天局的 1/3≈D2、2/3≈D3，**两条里程碑横幅挤在 5 天里** 😑 "刚开始就进度简报？" | **设计缺陷：极速局（5 天）不该套用 1/3·2/3 里程碑**，见 §5 必须修正 M1 |
| D5 结算 | 收益 -1.8%。设计的输局矩阵生效：首屏"本局带走了什么"+碎片 ×1 🙂→😌 "虽然输了但拿到个碎片，碎片是什么？" | **碎片无上下文**：首次获得必须带一句"集 3 块换一件藏品"（M2） |
| 复盘页 | 偏差诊断对 5 天 3 笔交易**样本太少**，诊断区要么空要么牵强 😕 | 极速局复盘应降级为"关键 2 个数字 + AI 对比"，不上全套诊断（M3） |
| 退出/再来 | "学费回收"奖励引导她点开了 AI 日志 🙂；结算页"再来一把"按钮在 → 点了第二局 ✅ | 动线成立。预估 5 分钟内完成 2 局 |

**小白链路结论**：极速局方向正确；三处设计缺陷（里程碑频率、碎片无上下文、复盘超载）都在 P0 内可修。

### 角色② 休闲玩家"老张"（一周上 2~3 次，每次 10 分钟，怕麻烦）

| 步骤 | 行为与情绪 | 关键观察 |
|---|---|---|
| 打开首页 | 有一局打到第 7 天的旧局。设计里"继续上局 ▸ 第 7 天"置顶替换极速局卡 😐 **摩擦：他其实不想续那局**（上次亏着，回避情绪），但续局占了 C 位，想开新极速局要多找一眼 | **续局卡必须和极速局并列而非替换**（M4）：回避旧局是休闲玩家常态，别用布局逼他面对 |
| 今日三签 | "玩一把极速局 / 做一次止损 / 猜对涨跌，完成两个" 🙂 "10 分钟正好干完" | 达预期：三签就是他的会话剧本 |
| 极速局中 | 挑战条"全程不满仓" 😏 "行，留一手" | 本局挑战对休闲玩家是**温和的注意力锚**，有效 |
| D4 | 想起有事，直接关页 😐 | 弃局无惩罚正确；**但明天回来旧局又占 C 位** → 同 M4 |
| 结算+1.2% | 赢了小钱 + 挑战达成勋章 🙂😊 双反馈节奏好 | 注意勋章 toast 和积分 toast 别叠弹（队列化已在 ux 方案） |
| 退出 | 三签完成 2/3，"明天的第三签"没有预告 😐 | 可选微调 O1：退出前轻提示"还差一签：猜对一次涨跌" |

**老张链路结论**：三签+极速局组合是休闲玩家的核心循环，成立；最大摩擦是**续局卡抢占 C 位**。

### 角色③ 硬核玩家"K 哥"（每天 1 小时，刷 HELL、研究复盘、已 100+ 局）

| 步骤 | 行为与情绪 | 关键观察 |
|---|---|---|
| 打开首页 | 😒 **"极速局大卡对我是噪音"**——他要的是每日挑战和房间。三签里"玩一把极速局"让他必须去打一个 5 天的 EASY 局 😠 | **设计缺陷：三签任务对硬核玩家不该含"必须极速局"**，任务文案应是"完成任意一局"（M5）。否则硬核玩家每天被迫降级游玩, 是对身份感的冒犯 |
| 开 HELL 正式局 | 本局挑战随机到"用一次挂单成交" 😑 "我本来就每局都挂单，白给" | 挑战对硬核玩家缺乏难度分层——P0 内低成本修法：挑战池按对局 AI 难度抽（HELL 局只抽难项，如"回撤 <5% 且跑赢 AI"）（M6） |
| 对局中 | 里程碑横幅第 7/20 天弹出 😐 "挡我看盘" | 横幅必须不遮 K 线与操作区，3 秒自隐 + 可在设置关"氛围层"（设计已有，确认覆盖里程碑）（O2） |
| 微反馈 | "分批进场，老手动作" 第 100 次看到 😒 | 微反馈对高频玩家快速钝化——每类文案准备 3 变体轮换 + 生涯累计 ≥20 次后自动静默该类（O3） |
| 结算 -0.4% 输给 HELL | 输局矩阵给碎片 😐 "无所谓" + **复盘是他真正的奖励** 🙂 诊断+AI 日志他全读 | 硬核玩家的输局奖励=信息本身，设计成立但对他几乎不靠碎片驱动 |
| 连输 3 局 | 触发降级提示"要不要去极速局找找手感？" 😠 **风险：对硬核玩家这句是嘲讽** | **必须修正 M7**：降级提示只对段位/局数低于阈值的玩家触发；硬核玩家连输时改为中性复盘入口（"连续 3 局：看看共同败因 →"） |
| 再开局 | 直奔同题约战（结算页主位）😊 | 高阶动线成立 |

**K 哥链路结论**：P0 对硬核玩家的价值在复盘与约战（已有），新增氛围层对他是轻度噪音——**可关闭 + 任务不强制降级游玩**是硬核留存的底线。

## 2. P0 四项效果评估

| P0 项 | 预期 | 仿真结论 |
|---|---|---|
| 首页 3 秒传达 | 三问有答 | **部分达标**：极速局/三签对新手与休闲 ✅；续局替换逻辑伤休闲玩家（M4）；对硬核玩家首屏价值密度下降（M5 缓解） |
| 极速局吸引力 | 低门槛随手玩 | ✅ 成立，且是新手唯一合理入口；但 5 天窗口与里程碑/复盘模板冲突（M1/M3） |
| 输局奖励机制 | 消除"输了白玩" | ✅ 对新手/休闲有效；对硬核近似无感（靠复盘自驱，无害）；碎片需首次上下文（M2） |
| 局内里程碑 | 维持局中动力 | ⚠ 对 20 天局有效、对 5 天局过密（M1）；对硬核是可容忍噪音，需可关 + 不遮挡（O2） |

## 3. 隐藏摩擦点清单（P0 设计之外、走查中暴露的现状问题）

1. **买卖数量输入**：新手不知道"手"的概念，输 150 被拒"必须 100 整数倍"——报错正确但晚了；数量框步进按钮默认 ±1 手可消掉这个报错的大半（文案级+input step）。
2. **"下一天"节奏**：连点 5 次推进时每次都有完整渲染动画，硬核玩家嫌慢——保持动画但确保 guarded 不吞连点节奏（点击排队感知）。
3. **结算弹窗出口歧义**："再来一把"对刚打完极速局的用户应再开极速局，对正式局用户应回开局卡——按钮文案须带类型（"再来一把极速局"）。
4. **三签的"猜对涨跌"**：依赖猜涨跌小游戏入口，但该入口在学堂域——三签项必须可点击直达对应入口，否则是"找路任务"。

## 4. 挫败防控机制风险评估

| 机制 | 结论 |
|---|---|
| 连输 3 局降级提示 | **有劝退风险**（K 哥场景）：按身份分流后风险消除（M7）；对新手保留原文案有效 |
| 奖励封顶（每类勋章赛季计 3 次） | 有效防通胀；风险是**玩家不知道封顶规则**在第 4 次达成时困惑"怎么没给"——达成但不计数时提示"本赛季该勋章已计满 3 次"（M8，文案级） |
| 输局碎片 | 防刷已由"结算时服务端判定+任务位封顶"覆盖；注意**极速局刷碎片**：5 天局快速弃打重开——碎片掉落绑定"完赛"且极速局日上限 2 次计数（设计已含任务位封顶，明确写进实现口径即可） |
| 首败安抚 | 有效；注意安抚文案只在**首局**出现，第二局输了再安抚会显得敷衍 |

## 5. P0 内微调清单

**【必须修正】（实装前改设计）**
- **M1** 极速局不套用 1/3·2/3 里程碑：5 天局只在 D3 出一条"过半简报"，或完全不弹
- **M2** 首次获得碎片附带一句机制说明（"集 3 块 → 1 件藏品"），仅首次
- **M3** 极速局复盘降级模板：收益 vs 持有基准 + AI 对比两项，不渲染偏差诊断（样本不足）
- **M4** 续局卡与极速局卡**并列**展示，不替换；续局卡带当前浮盈亏小字（让他自己决定面不面对）
- **M5** 三签任务项用"完成任意一局"替代"玩一把极速局"（极速局只是对新手的默认推荐位，不是义务）
- **M6** 本局挑战池按 AI 难度分层抽取（EASY 池/HELL 池），避免硬核白给与新手不可能
- **M7** 连输降级提示按玩家局数分流：<10 局给极速局出口；≥10 局给"共同败因"复盘入口
- **M8** 勋章计满封顶时给明确反馈文案

**【可选微调】**
- O1 退出前"还差一签"轻提示（一次/日）
- O2 里程碑横幅不遮 K 线与操作区、3 秒自隐、纳入"氛围层"总开关
- O3 微反馈每类 3 文案变体 + 生涯 ≥20 次自动静默
- O4 数量输入框步进=1 手（§3.1）
- O5 结算"再来一把"按钮带局型文案（§3.3）

## 7. 总结

- P0 方向在**新手与休闲**两类人群成立（出发大厅+极速局+三签构成完整会话剧本）；对**硬核玩家**的正确姿态是"可关闭、不强制、不降级对待"——M5/M7 是硬核留存的两条底线修正。
- 8 条必须修正全部为设计/文案层调整，不扩 P0 范围、不触撮合结算；建议并入实装需求一次做掉。
- 本报告全部结论待 §6 埋点上线后以真实数据复核；与真实数据冲突时，以数据为准废弃对应推演。
