# QuantSim Release Notes · 2026-10 Bug 修复版

**本次共修复 13 处问题**：3 高危、6 中危、4 低危，另对每日挑战并发路径做了加固。
无数据库结构变更，前端静态资源已更新版本号（用户强刷即可获取最新）。

---

## 🔴 重点修复（高危）

### 1. 排行榜漏人 / 名次不准
- **用户感知**：真实玩家结算后进不了榜单前列，被测试账号"挤掉"名次。
- **说明**：自动化测试账号的成绩之前会占用榜单名额。现已在取数时直接排除，真实玩家名次完整准确。涉及收益榜、夏普榜、积分榜、竞技场榜、每日榜全部公开榜单。

### 2. 邮箱用户的"我的成绩"显示异常
- **用户感知**：用邮箱注册的用户，在每日挑战看不到"我的百分位"，上月进前三也拿不到颁奖台称号。
- **说明**：榜单对邮箱用户名做了隐私打码（`cl***@…`），导致前端认不出"哪条是我"。现由服务端直接标记本人记录，百分位和称号恢复正常。**同时修复**：很短的邮箱（如 `ab@…`）之前打码不彻底，现已完全遮挡。

### 3. 好友房间到期后打不开（页面报错）
- **用户感知**：好友房间到期结算时，若有成员的对局数据异常，整个房间页会持续报错、再也打不开。
- **说明**：单个成员结算失败不再影响整个房间——失败的成员单独跳过，房间正常进入"已结算"，页面可正常访问。

## 🟡 功能优化（中危）

### 4. 注册 / 每日挑战"手慢了"的提示更友好
- **用户感知**：同一时刻重复注册同名、或连点两次"开始每日挑战"，之前会弹"服务器错误"，现在是清晰的业务提示（"用户名已被注册""今天已经玩过"）。
- **说明**：并发冲突从"系统报错"转为"友好提示"；每日挑战的并发路径一并做了稳定性加固。

### 5. 异常行情不再导致页面崩溃
- **用户感知**：极少数异常行情数据（价格为 0）之前会让对局/回测直接报错，现在会安全跳过。
- **说明**：对价格为 0 的坏数据增加了防护，避免计算异常。

### 6. "每日一猜"防刷优化
- **用户感知**：之前可以靠刷新页面无限重开当天的"每日一猜"，跨零点完成还会占用第二天的名额。现已按"开局即计入当天"处理。
- **提示产品/测试**：误触"每日一猜"后立即退出也会消耗当天次数——这是防刷的有意设计，非 bug。

### 7. 高并发下的限流更稳
- **用户感知**：无直接感知。
- **说明**：请求限流在高并发清理场景下的一个边界竞态已兜底，防止限流被短暂绕过。

## 🟢 细节兜底（低危）

### 8. 擂台历史记录显示更准
- **用户感知**：擂台榜里一些旧记录的"最大回撤"之前错误显示成 `+0.0%`，现在无数据时显示 `--`。

### 9. 游客身份更稳定
- **用户感知**：隐私模式/禁用存储的游客，之前每次操作会换一个随机昵称，导致同一局的记录对不上。现在单次访问内昵称保持一致。

### 10. 小游戏"通关数"统计更准
- **用户感知**：个人主页的"小游戏通关数"之前会把"只开了一局没通关"的也算进去，数字虚高。现在只统计真正通关的玩法。

### 11. "事件回放"页刷新不再空白
- **用户感知**：停在"事件回放"页刷新后场景数量不显示的问题已修复。

### 12. 错误提示更健壮
- **用户感知**：无直接感知。
- **说明**：页面对接口错误的判断不再依赖具体中文文案，改用标准状态码，避免文案调整后逻辑失效。

## ⚠️ 已知限制

- **测试账号前缀撞名**：若真实用户的注册名恰好以 `smoke_ / btncheck_ / shot_` 开头，会被当作测试账号、从公开榜隐藏。**后续将在注册入口加保留字限制**；当前如遇到请联系改名。
- **每日一猜次数**：开局即计入当天次数（见第 6 条），误触也会消耗——有意设计。
- **时区**：榜单周期/倒计时按部署时区计算，当前面向中国时区；多时区场景待后续适配。

## 🧪 测试关注点（给测试同学）

> 本轮改动集中在"榜单取数 / 用户名隐私 / 房间与每日挑战的结算与并发"，回归重点如下。

1. **榜单取数**（最高优先）：造"测试账号高分 + 真实玩家"的数据，确认真实玩家名次完整、测试账号不出现、邮箱用户名已打码。
2. **邮箱用户自我识别**：邮箱账号打每日挑战并结算，确认能看到"我的百分位"；上榜前三确认拿到称号。
3. **房间到期结算**：构造"部分成员数据异常"的到期房间，确认房间页正常打开、进入已结算、反复刷新不报错。
4. **并发**：同时重复注册同名 / 连点每日挑战，确认是友好提示而非系统报错。
5. **每日一猜防刷**：开局后刷新再进，确认提示"今天已玩"；跨零点完成记在开局当天。
6. **细节回归**：擂台旧记录回撤显示 `--`、小游戏通关数、事件回放页刷新、隐私模式游客昵称一致。

**自动化现状**：后端 84 项测试全通过；前端静态检查、死按钮检查、全站点击爬虫、关键流程冒烟均 0 错误。上线后建议按 `docs/release-acceptance.md` 的 5 分钟冒烟脚本做一次线上核验。
